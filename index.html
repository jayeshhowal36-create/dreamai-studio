Tutorials & API

How to use DreamAI Studio

1. Choose a creation tool from the sidebar.
2. Upload your own media when needed.
3. Preview or prepare your prompt.
4. Save project notes in My Creations.

To enable actual AI video, image animation or face swap, a backend service and model/API connection must be configured. Never paste private API keys into public GitHub HTML/JavaScript. Keep keys on a secure server.
